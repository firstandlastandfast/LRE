# RL - RocketLab
Personal liquid rocket design app. Modules: CORE, MISSION, VEH, TRADE, THERMO, CHAMBER, INJ, FEED, TP, SYS, TEST, CAL, UI.
Preliminary-design estimates only; not a substitute for engineering review and testing.

## Run
- Windows: double-click `RocketLab.bat`
- Mac/Linux: `./RocketLab.sh`

- https://liquidrocketengine.streamlit.app/
